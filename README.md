# Railway Transport Management

A data analysis and visualization project focused on railway transportation data and insights.

## Team Members

* **Pallavi** — Data Analysis using Jupyter Notebook
* **Visha** — Dashboard Development using VS Code and Streamlit

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* Streamlit

## Project Work

**Pallavi:** Performed data cleaning, exploratory data analysis (EDA), and data visualization using Jupyter Notebook.

**Visha:** Developed an interactive Streamlit dashboard to present and explore the analyzed railway data.

## Objective

To analyze railway transportation data, identify useful insights, and present them through an interactive dashboard.

## Run Dashboard

```bash
pip install -r requirements.txt
streamlit run app.py
```
